# Resources

这里保存“别人已经做好的东西”和自己的历史整理，不放本项目运行时生成的原始数据。

## 分类

- `Papers/`：论文、预印本、论文引用信息和与论文配套的材料。
- `Documentation/`：官方说明、技术文档、API 文档、方法说明。
- `Project_Introductions/`：开源项目介绍、项目主页导出资料、架构概览和项目调研。
- `Historical_Progress/`：自己整理的阶段总结、时间线、决策记录和里程碑。
- `Notes/`：阅读笔记、主题综述、概念解释和待验证想法。

## 建议命名

文件名只使用英文，例如：

`2026-08-04_author_short_title.pdf`

如果原始文件名很复杂，保留一个英文规范名，并在同目录的说明文档中记录原始来源和 URL。中文内容可以写在 Markdown 说明文档中。

## 资料记录要求

每份重要资料至少记录：来源、作者/机构、发布日期、访问日期、链接、核心结论、与 Predictive Agents 的关系，以及需要复现或验证的部分。
